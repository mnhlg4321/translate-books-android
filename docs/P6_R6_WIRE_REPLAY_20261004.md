# Replay a captured P6 wire response offline

The fixture runner stores only the model response content bytes under
`D:\P5E-private\p6-runs\<run-id>\results\<fixture-id>\responses\`.
Files use an ordered name such as `001-L1_RAW_DISCOVERY.json` or
`002-L1_RECONCILE.json`. They contain no request headers or credentials.

Run these commands from the repository root. They read local fixture and
response files and do not contact a provider.

```powershell
.\gradlew.bat --offline :editorial-engine:replayP6WireResponse `
  -Pp6ReplayPhase=L1_RAW_DISCOVERY `
  "-Pp6ReplayResponse=D:\P5E-private\p6-runs\<run-id>\results\<fixture-id>\responses\001-L1_RAW_DISCOVERY.json" `
  "-Pp6ReplayRaw=D:\P5E-private\p6-fixtures\<fixture-id>\RAW.txt"
```

For reconcile, include the same fixture's DRAFT and the captured RAW response:

```powershell
.\gradlew.bat --offline :editorial-engine:replayP6WireResponse `
  -Pp6ReplayPhase=L1_RECONCILE `
  "-Pp6ReplayResponse=D:\P5E-private\p6-runs\<run-id>\results\<fixture-id>\responses\002-L1_RECONCILE.json" `
  "-Pp6ReplayRaw=D:\P5E-private\p6-fixtures\<fixture-id>\RAW.txt" `
  "-Pp6ReplayDraft=D:\P5E-private\p6-fixtures\<fixture-id>\DRAFT.txt" `
  "-Pp6ReplayRawResponse=D:\P5E-private\p6-runs\<run-id>\results\<fixture-id>\responses\001-L1_RAW_DISCOVERY.json"
```

Successful parsing prints a `PASS` line. A refusal prints the safe
`CODE:path` value and exits with status 2. The path is generated by the app's
parser; unrecognized model-supplied keys and values are never copied into it.
